# План проекта Lumo (рабочая версия для Claude Code)

Полная версия с пояснениями — документ «План проекта Lumo» у владельца. Здесь — то, что нужно исполнителю каждый день.

## Допущения

- Исполнитель — Claude Code; владелец ставит задачи, проверяет сборки на устройствах, подтверждает разрешения и подписи, принимает решения в контрольных точках.
- Около 20 часов участия владельца в неделю. Темп ограничен циклом «задача → сборка → проверка на устройстве», а не скоростью написания кода.
- Двухнедельные спринты, в конце каждого — рабочая сборка.
- Старт — 2 ноября 2026 года. Запас около 15% на отладку системных API Apple.
- Без платного членства Apple Developer доступны: Xcode, запуск своих сборок на своих устройствах. Платное (99 USD/год) нужно для iCloud/CloudKit, TestFlight и публикации — оплачивается перед проверкой 0.6.

## Главные риски

R1 нехватка времени владельца → приоритет Mac, перенос спринта 8 в v1, а не сдвиг релиза · R2 прямая вставка в песочнице → запасной вариант · R3 захват в Mac App Store → продажа с сайта · R4 ошибки синхронизации → проверка 0.6, тесты конфликтов · R5 название Lumo занято → выбрать до беты · R6 отказ проверки Apple → пояснения и видео · R7 изменения ОС после WWDC → бета ОС в v1-6 · R8 неверный код для системных API → старшая модель, маленькие шаги, ручная проверка · R9 конкуренты → всё в одном, RU/UZ интерфейс, цена.
