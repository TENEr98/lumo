# Ограничения платформы Apple

Каждая строка — факт с последствием и принятым решением. Факты, которые ещё не проверены на прототипе, помечены «проверить».

| Ограничение | Последствие | Решение | Статус |
| --- | --- | --- | --- |
| iOS не даёт стороннему приложению снимать чужой экран | На iPhone нет режимов «область», «окно», «таймер» | Импорт системных скриншотов из «Фото» и через «Поделиться» | факт |
| iOS 16+: программное чтение буфера вызывает запрос «Разрешить вставку»; фоновое чтение запрещено | История на iPhone сама не пополняется | Источник — Mac через iCloud; «Поделиться», «Команды», чтение при открытии с разрешением пользователя | факт |
| Расширение трансляции ReplayKit: лимит памяти порядка 50 МБ, остановка при блокировке и звонке | Запись может теряться при неаккуратной реализации | Запись потоком на диск, корректное закрытие файла | факт; цифру проверить на устройстве |
| Расширение «Поделиться»: лимит памяти порядка 120 МБ | Тяжёлая обработка приводит к вылету | Расширение только сохраняет файл | факт; проверить |
| Захват экрана требует разрешения «Запись экрана и системного звука» | Без разрешения — пустые снимки | Онбординг, проверка `CGPreflightScreenCaptureAccess` | факт |
| macOS 15+: периодическое повторное подтверждение доступа к записи экрана; программно не отключается | Пользователь иногда видит системный запрос | Объяснение в онбординге | факт для macOS 15; поведение в текущей macOS проверить |
| `SCScreenshotManager` — macOS 14+, запись в файл через ScreenCaptureKit — macOS 15+ | Разные пути записи на 14 и 15+ | `if #available`, на 14 — `SCStream` + `AVAssetWriter` | факт |
| ⌘⇧3/4/5 нельзя перехватить | Нельзя заменить системный скриншотер | Свои сочетания + инструкция | факт |
| RAR: лицензия UnRAR разрешает только распаковку | Создание RAR невозможно | Создаём ZIP и 7z | факт |
| Нет официальных Rust-SDK Apple; сторонняя обёртка CloudKit — только macOS | Чистый Rust невозможен | Rust — ядро, Swift — системные API | факт |
| Прямая вставка требует «Универсального доступа»; совместимость с песочницей Mac App Store не подтверждена | Вставка «в одно нажатие» под вопросом | Проверка 0.4, запасной вариант | проверить |
| DRM-контент отдаётся чёрными кадрами | Чёрный экран в записи стриминга | Предупреждение в справке | факт |
| iCloud/CloudKit, TestFlight, публикация требуют платного членства (99 USD/год) | До оплаты нельзя проверить синхронизацию | Оплата перед проверкой 0.6 | факт |

Источники — в `09-sources.md`. Новые ограничения, найденные в работе, добавлять сюда с источником или ссылкой на эксперимент.
