# Зависимости и лицензии

Допустимые лицензии: MIT, Apache-2.0, BSD-2/3, ISC, Zlib, MPL-2.0. Недопустимы: GPL, AGPL, LGPL при статической линковке. Исключение по смыслу — UnRAR: собственная лицензия, используется только для распаковки.

Перед добавлением проверь лицензию на crates.io или в репозитории и впиши строку. Пустая колонка «Проверено» означает, что зависимость ещё не добавлена.
