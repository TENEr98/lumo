# Архитектура

Одно Rust-ядро и три тонкие нативные оболочки на Swift. Ядро делает платформенно-независимую работу с данными, Swift — всё, что касается системы Apple. Решение зафиксировано в ADR-001.

```
┌────────────── Lumo macOS ──────────────┐ ┌──────── Lumo iOS / iPadOS ────────┐
│ SwiftUI + AppKit: строка меню, оверлей,│ │ SwiftUI, PencilKit                │
│ горячие клавиши                        │ │ Расширения: «Поделиться»,         │
│                                        │ │ ReplayKit, клавиатура             │
└───────────────┬────────────────────────┘ └──────────────┬────────────────────┘
                │            LumoKit (Swift-пакет)         │
                │  Services · Features · DesignSystem      │
                ├──────────────────┬───────────────────────┤
                │ UniFFI           │ системные API         │
        ┌───────▼────────┐  ┌──────▼──────────────────────────────┐
        │ lumo-core      │  │ ScreenCaptureKit, AVFoundation,     │
        │ (Rust)         │  │ Vision, ReplayKit, PencilKit,       │
        │ storage,       │  │ CloudKit (CKSyncEngine)             │
        │ archive,       │  └──────────────┬──────────────────────┘
        │ imaging,       │                 │
        │ clipboard,     │        ┌────────▼─────────────────────────┐
        │ sync-model     │        │ iCloud пользователя: частная база│
        └────────────────┘        │ CloudKit, зона LumoZone          │
                                  └──────────────────────────────────┘
```

## Крейты ядра

| Крейт | Ответственность |
| --- | --- |
| `storage` | SQLite (WAL), миграции, FTS5, CRUD элементов, пагинация |
| `archive` | Чтение и создание ZIP, 7z, TAR, gz/bz2/xz/zst; чтение RAR; кодировки; защита |
| `imaging` | Обрезка, размытие, пикселизация, склейка, сжатие под размер, миниатюры, GIF |
| `clipboard` | Модель элемента буфера, дедупликация, правила хранения |
| `sync-model` | Сериализация в записи CloudKit, версии, слияние |
| `ffi` | Экспорт через UniFFI, единственная публичная поверхность |

## Сервисы Swift (LumoKit)

`LibraryStore`, `CaptureService`, `RecordingService`, `MediaEditingService`, `PasteboardMonitor`, `SyncService`, `PermissionCenter`, `OCRService`. Каждый — за протоколом с заглушкой.

## Потоки

1. **Создание:** системный захват/копирование → файл в общем контейнере → `LibraryStore.add` → ядро пишет метаданные, строит миниатюру, индексирует текст.
2. **OCR:** `OCRService` (Vision) распознаёт текст изображения в фоне → ядро добавляет в FTS5.
3. **Синхронизация вверх:** ядро отдаёт изменённые элементы → `SyncService` → CKSyncEngine.
4. **Синхронизация вниз:** CKSyncEngine → `SyncService` → ядро применяет по правилам `sync-model`.
5. **Расширения iOS** пишут файл и маленький JSON в общий контейнер; основное приложение импортирует при запуске. Ядро в расширение записи не подключается (лимит памяти).

## Файлы

Общий контейнер группы приложений: `library.sqlite`, `media/<id>/original.*`, `media/<id>/thumb.jpg`, `projects/<id>.json`, `inbox/` (входящие от расширений), `sync/engine-state.bin`.

## Принятые технологические решения

См. `../decisions.md`: ADR-001 (Rust-ядро + Swift), ADR-002 (AVFoundation вместо FFmpeg), ADR-003 (частная база CloudKit, без своих серверов), ADR-004 (RAR только распаковка), ADR-005 (Mac — основная платформа), ADR-006 (SwiftUI общий для платформ), ADR-007 (без сторонних SDK).
