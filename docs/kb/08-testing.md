# Тестирование

Требование выполнено, когда пройден его критерий приёмки (раздел 13 БФТ): автотестом, где возможно, и ручной проверкой владельца, где нельзя. Подробности и шаблон сценария — скилл `acceptance-testing`.

## Уровни

| Уровень | Где | Что |
| --- | --- | --- |
| Модульные Rust | `core/crates/*/src` | Логика ядра |
| Интеграционные Rust | `core/crates/*/tests` | Архивы на эталонных файлах, хранилище, слияние записей |
| Производительность | `#[ignore]`-тесты | Поиск на 50 000 элементов (NFR-08) |
| Swift | `LumoKit/Tests` | Модели представлений с заглушками сервисов, вызов ядра через FFI |
| Ручные сценарии | `docs/test-scripts/<код>.md` | Разрешения, захват, запись, синхронизация, интерфейс |

## Устройства

Mac (актуальная macOS и macOS 14 в отдельной учётной записи или виртуальной машине), iPhone (актуальная iOS), iPad Pro (актуальная iPadOS). Синхронизация проверяется только с одним Apple ID на Mac и iPhone одновременно.

## Тестовые данные (`testdata/`, генерируются `scripts/gen-testdata.sh`)

- ZIP с именами в CP866 и без флага UTF-8; ZIP с путями `../`; архивная бомба; 7z с паролем; RAR5 с паролем (готовый файл из открытого источника с указанием лицензии — сами RAR не создаём).
- Изображения: 1×1, 5120×2880, PNG с прозрачностью, HEIC.
- Видео: 10 с и 5 мин, 60 к/с, со звуком.
- Библиотека на 50 000 синтетических элементов для замеров.

## Обязательные проверки безопасности

Распаковка не пишет за пределы папки назначения; размытие необратимо в экспорте; скрытые элементы буфера нигде не сохраняются.
