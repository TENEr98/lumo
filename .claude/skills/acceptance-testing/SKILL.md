# Приёмка задач

## Правило

Требование выполнено, когда пройден его критерий приёмки: автотестом там, где это возможно, и ручной проверкой владельца там, где нельзя (разрешения ОС, захват экрана, запись, синхронизация между устройствами, ощущение от интерфейса).

## Шаблон сценария ручной проверки (`docs/test-scripts/<код>.md`)

```markdown
# <код>: <название требования>

Устройство и ОС: <Mac, macOS 15 / iPhone, iOS 18 …>
Сборка: <коммит или номер TestFlight>
Подготовка: <что должно быть до начала: чистая установка, вход в iCloud, тестовый файл …>

| № | Действие | Ожидаемый результат | Факт (заполняет владелец) |
| --- | --- | --- | --- |
| 1 | … | … | |

Итог: прошло / не прошло. Замечания: …
```

Шаги короткие и однозначные; один шаг — одно действие. Ожидаемый результат — наблюдаемый (что видно, сколько секунд, какой файл).

## Матрица устройств

| Проверка | Минимальная ОС | Последняя ОС |
| --- | --- | --- |
| Mac | macOS 14 (отдельная учётная запись или виртуальная машина) | актуальная macOS |
| iPhone | iOS 17 (если есть устройство, иначе симулятор для интерфейса) | актуальная iOS |
| iPad | — | актуальная iPadOS |

## Тестовые данные

`testdata/` с генераторами: ZIP с CP866-именами, ZIP с `../`, архивная бомба, 7z с паролем, RAR5 с паролем, изображения разных размеров, видео 10 с / 5 мин.

## Отметка

После ручной проверки — строка в `docs/progress.md`: код, дата, устройство, итог, ссылка на сценарий.
