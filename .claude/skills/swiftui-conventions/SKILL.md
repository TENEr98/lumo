# Интерфейс Lumo

## Структура

```
apple/Packages/LumoKit/Sources/
  LumoCore/        # сгенерированные привязки к ядру (не править вручную)
  Services/        # CaptureService, RecordingService, SyncService, …
  Features/
    Library/  Editor/  Recorder/  VideoEditor/  Archive/  Clipboard/  Settings/  Onboarding/
  DesignSystem/    # DesignTokens, общие компоненты
```

Каждая фича: `XView.swift`, `XModel.swift` (`@Observable`), превью с заглушками сервисов.

## Состояние

- `@Observable` модели, внедрение сервисов через окружение (`@Environment`).
- Никакой бизнес-логики во `View`. Никаких синглтонов, кроме точки сборки зависимостей в приложении.
- Все вызовы ядра и системных сервисов — `async`, вне главного потока; обновление состояния — на `@MainActor`.

## Платформы

- По умолчанию код общий. Расхождения — через `#if os(macOS)` в маленьких местах или через отдельные представления-обёртки.
- Mac: строка меню (`MenuBarExtra`), настройки (`Settings`), панели поверх окон и оверлей выбора области — AppKit (`NSPanel`, `NSWindow` с уровнем выше обычного).
- iPad: разделённый вид, поддержка трекпада и клавиатуры, Apple Pencil в редакторе.

## Токены дизайна

`DesignTokens`: цвета (семантические, со светлой и тёмной темой), отступы (4, 8, 12, 16, 24, 32), радиусы (6, 10, 14), шрифты (системные стили). В коде фич — только токены.

## Состояния каждого экрана

Загрузка, пусто, данные, ошибка, нет разрешения, нет iCloud. Для каждого — превью.

## Доступность

Метки VoiceOver на всех кнопках-иконках, динамический шрифт без обрезки, контраст в обеих темах, полное управление с клавиатуры на Mac (фокус, сочетания).

## Производительность

- Библиотека — `LazyVGrid`/`List` с пагинацией из ядра, миниатюры из файлов ядра, а не из оригиналов.
- Окно быстрого доступа и панель буфера создаются заранее и скрываются, а не строятся при каждом вызове (NFR-05 — NFR-07).
