# История буфера обмена

## Mac: слежение

- Уведомления об изменении буфера в AppKit нет: опрашивай `NSPasteboard.general.changeCount` по таймеру (примерно каждые 0,5 с, с послаблением при простое и работе от батареи).
- При изменении — прочитать доступные типы и сохранить самый богатый плюс текстовый вариант: файлы (`public.file-url`), изображения (`public.png`, `public.tiff`), форматированный текст (`public.rtf`, `public.html`), ссылки (`public.url`), простой текст (`public.utf8-plain-text`).
- Приложение-источник — `NSWorkspace.shared.frontmostApplication` в момент изменения.

## Приватность (CLP-05)

- Не сохранять и не синхронизировать элементы, где присутствуют маркеры соглашения nspasteboard.org: `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`.
- Список исключённых приложений (по умолчанию — известные менеджеры паролей), пауза записи из строки меню.
- Собственные записи Lumo в буфер помечаются своим типом, чтобы не попадать в историю повторно.

## Хранение (в ядре)

Дедупликация по хэшу содержимого (повтор поднимает элемент наверх), лимит по числу или возрасту, закреплённые не удаляются (CLP-06). Большие изображения и файлы — в `media/`, в базе только ссылки.

## Вставка (CLP-02, проверка 0.4)

- Основной путь: положить элемент в буфер, вернуть фокус предыдущему приложению, сымитировать ⌘V через `CGEvent` — требует разрешения «Универсальный доступ» (`AXIsProcessTrustedWithOptions`).
- Совместимость этого пути с песочницей Mac App Store проверяется в этапе 0. Если не проходит — запасной путь: элемент в буфере + подсказка «нажмите ⌘V».
- Вставка без форматирования — записывать только простой текст.

## iOS

- Фоновое чтение буфера запрещено; программное чтение (`UIPasteboard.general`) с iOS 16 вызывает системный запрос, если пользователь не включил «Вставка из других приложений» в настройках Lumo.
- Пополнение истории: при открытии приложения (по разрешению), через расширение «Поделиться», через действие App Intents для «Команд», с Mac через синхронизацию (CLP-08).
- Для проверки наличия данных без чтения — `UIPasteboard.general.hasStrings`/`detectPatterns`; для вставки по кнопке — `UIPasteControl`.
- Клавиатура (CLP-09, v1) читает историю из общего контейнера; ей нужен «Полный доступ», и это объясняется пользователю.
