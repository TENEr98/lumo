# Локализация

## Языки

Русский (основной язык разработки), узбекский на латинице, английский. Узбекский — латиница, не кириллица.

## Механика

- Xcode String Catalog (`Localizable.xcstrings`) в LumoKit и в каждом расширении со своими строками.
- В коде — `String(localized: "library.empty.title", defaultValue: "Здесь пока пусто", comment: "…")` или `Text("library.empty.title")`.
- Ключи — `фича.экран.элемент`, комментарий обязателен: где показывается и сколько места.
- Множественное число — через вариации в каталоге (русский: one/few/many/other).
- Числа, даты, размеры файлов — через форматтеры (`formatted()`, `ByteCountFormatStyle`), не вручную.

## Проверка

Переключить язык системы на каждый из трёх и пройти основные экраны: нет обрезанных строк, нет ключей вместо текста, нет английских вставок.
