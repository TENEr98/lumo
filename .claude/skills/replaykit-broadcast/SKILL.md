# Запись экрана на iOS (ReplayKit)

## Устройство

- Цель «Broadcast Upload Extension» с классом-наследником `RPBroadcastSampleHandler`.
- Кадры приходят в `processSampleBuffer(_:with:)` с типами `.video`, `.audioApp`, `.audioMic`.
- Запуск из приложения — `RPSystemBroadcastPickerView` с `preferredExtension` = идентификатор нашего расширения; либо из Пункта управления (долгое нажатие на кнопку записи).
- Приложение и расширение входят в одну общую группу приложений; файл записи пишется в её контейнер.

## Лимит памяти

Расширение работает в отдельном процессе с жёстким лимитом памяти (порядка 50 МБ). Поэтому:

- никаких буферов кадров в памяти — сразу в `AVAssetWriter`;
- без тяжёлых библиотек и Rust-ядра в расширении (только запись файла и маленький JSON с метаданными);
- `expectsMediaDataInRealTime = true` у входов writer;
- при `isReadyForMoreMediaData == false` кадр пропускается, а не накапливается.

## Начало и конец

- Сессия writer стартует по времени первого видеокадра (`startSession(atSourceTime:)`).
- `broadcastFinished()` вызывается при остановке пользователем; система также останавливает трансляцию при блокировке экрана и звонке. Во всех случаях — `markAsFinished` у входов и `finishWriting`, дождаться завершения синхронно в пределах отведённого времени.
- При первом запуске основного приложения после записи — найти незавершённые файлы, попытаться восстановить или пометить как повреждённые, импортировать в библиотеку.

## Звук

- Системный звук приложений и микрофон — отдельные дорожки (REC-02); микрофон включается пользователем в системном окне трансляции.

## Ограничения, о которых сообщать пользователю

- Защищённый контент (DRM) записывается чёрным кадром.
- Симулятор запись не поддерживает — проверка только на устройстве.

## Проверка (вручную, на iPhone)

1. Запуск из приложения, запись 10 минут, остановка из Пункта управления — файл в библиотеке, воспроизводится.
2. Блокировка экрана во время записи — файл сохранён до момента блокировки.
3. Инструменты Xcode → память расширения не превышает лимит на всём протяжении.
