# ScreenCaptureKit в Lumo

## Основные типы

- `SCShareableContent` — список дисплеев, окон и приложений; получать асинхронно перед каждым захватом (окна меняются).
- `SCContentFilter` — что снимать: дисплей целиком с исключением приложений/окон или одно окно.
- `SCStreamConfiguration` — размер, частота кадров, курсор, формат пикселей, захват звука.
- `SCScreenshotManager.captureImage(contentFilter:configuration:)` — одиночный снимок, macOS 14+.
- `SCStream` + `SCStreamOutput` — поток кадров и звука для записи (macOS 12.3+); `SCRecordingOutput` — запись сразу в файл, macOS 15+.

Сигнатуры сверяй с документацией Apple перед использованием: API добавлялся по версиям.

## Режимы снимка

- Экран: фильтр по дисплею, исключая собственное приложение (SCR-07).
- Окно: фильтр по `SCWindow`; тень и фон добавляются после захвата в ядре или Core Image.
- Область: снимок дисплея + обрезка по прямоугольнику с учётом масштаба Retina (`pointPixelScale` дисплея). Оверлей выбора области — отдельное окно AppKit поверх всех, исключённое из захвата.

## Разрешение

- Проверка: `CGPreflightScreenCaptureAccess()`; запрос: `CGRequestScreenCaptureAccess()` (открывает системный диалог один раз).
- После выдачи разрешения часто нужен перезапуск приложения — показывай кнопку «Перезапустить».
- С macOS 15 система периодически повторно спрашивает подтверждение; отключить программно нельзя. Онбординг объясняет это заранее.
- Описание для пользователя — в онбординге; системная строка задаётся самой ОС.

## Горячие клавиши

- В песочнице используй Carbon `RegisterEventHotKey` (или проверенную обёртку): не требует разрешения универсального доступа.
- Системные ⌘⇧3/4/5 перехватить нельзя — по умолчанию свои сочетания.

## Производительность

- Не держи `SCShareableContent` закэшированным дольше одного действия.
- Для записи 60 к/с: формат `kCVPixelFormatType_420YpCbCr8BiPlanarVideoRange`, кодирование аппаратное (через `AVAssetWriter` с HEVC/H.264).

## Проверка (вручную, на Mac)

1. Чистая установка, первый снимок — появляется онбординг разрешения.
2. После выдачи — снимок области, окна, экрана; собственные окна не видны.
3. Сборка с песочницей (Archive → Export for App Store) — всё то же самое работает.
