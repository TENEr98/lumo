# Выпуск

## Перед первой бетой

- [ ] Платное членство Apple Developer активно (99 USD в год).
- [ ] Идентификаторы приложений, общая группа приложений, iCloud-контейнер созданы для всех целей.
- [ ] Mac- и iOS-приложения используют один идентификатор пакета для универсальной покупки (проверить актуальные правила Apple перед настройкой).
- [ ] Версия по схеме `MAJOR.MINOR.PATCH`, номер сборки растёт автоматически.
- [ ] Строки описания разрешений в Info.plist: микрофон, камера (v1), «Фото» (импорт скриншотов), понятным языком на трёх языках.
- [ ] Экран «Лицензии» с текстами лицензий зависимостей, включая UnRAR.

## Страница в App Store

- [ ] Название проверено по поиску App Store и базам товарных знаков.
- [ ] Подзаголовок, описание, ключевые слова, «Что нового» — русский, узбекский, английский (`release/<версия>/`).
- [ ] Скриншоты для Mac и iPhone, короткое видео — снятые в самом Lumo.
- [ ] Ссылки на политику конфиденциальности и поддержку.
- [ ] Метки конфиденциальности: «Данные не собираются» — сверено с кодом (нет аналитики, нет сторонних SDK, синхронизация только в iCloud пользователя).

## Пояснения для проверяющих

Кратко и по пунктам: зачем запись экрана (снимки и запись по команде пользователя), зачем «Универсальный доступ» (вставка из истории буфера, если используется), почему приложение читает буфер на Mac (функция истории, исключения для паролей), где это видно в интерфейсе; демонстрационное видео.

## Деньги

- [ ] Вступление в App Store Small Business Program (15% вместо 30% при доходе до 1 млн USD в год).
- [ ] Модель оплаты решена владельцем: разовая покупка или подписка.

## Подача

Инструкция для владельца по шагам: архив в Xcode → загрузка в App Store Connect → выбор сборки → заполнение версии → отправка на проверку. Источник требований — актуальные страницы developer.apple.com, а не память.
