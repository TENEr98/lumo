# Редактор изображений

## Принцип

Исходное изображение — нижний слой, никогда не меняется. Всё нарисованное — список объектов в проекте. Экспорт = исходник + отрисованные объекты + необратимо применённые размытия.

## Формат проекта (`projects/<id>.json`)

```json
{
  "version": 1,
  "itemId": "uuid",
  "canvas": { "width": 2880, "height": 1800, "crop": null, "rotation": 0,
              "background": null, "padding": 0, "cornerRadius": 0, "shadow": false },
  "objects": [
    { "id": "uuid", "type": "arrow", "from": [0.1, 0.2], "to": [0.4, 0.5],
      "style": { "color": "#FF3B30", "width": 6, "head": "filled", "curve": 0 } },
    { "id": "uuid", "type": "text", "origin": [0.5, 0.1], "text": "Ошибка здесь",
      "style": { "font": "system", "size": 32, "color": "#FFFFFF", "backdrop": "#000000CC" } },
    { "id": "uuid", "type": "blur", "rect": [0.6, 0.6, 0.2, 0.1], "mode": "pixelate", "strength": 12 },
    { "id": "uuid", "type": "counter", "center": [0.2, 0.8], "value": 1 }
  ]
}
```

Координаты — в долях от размера холста, чтобы проект переживал масштабирование. Типы объектов: `arrow`, `line`, `rect`, `ellipse`, `text`, `pen`, `highlighter`, `blur`, `counter`, `spotlight`, `magnifier`.

## Отрисовка

- В интерфейсе — SwiftUI `Canvas` (или Core Graphics) поверх изображения; объекты рисуются одним кодом и в предпросмотре, и при экспорте (один рендерер `AnnotationRenderer`).
- Свободное рисование на iPad — PencilKit; результат конвертируется в объект `pen` с точками и нажимом.

## Отмена и повтор

Команды над списком объектов (`add`, `update`, `remove`, `reorder`) с обратными операциями; стек без ограничения длины в пределах сессии (IMG-07).

## Размытие — безопасность (IMG-05)

- При экспорте пиксели под объектом `blur` заменяются в растре ядром (`imaging::pixelate`/`imaging::blur`) **до** наложения остальных объектов.
- Экспортированный файл не содержит слоёв, исходника и метаданных с исходными пикселями.
- Тест: сравнение экспортированной области с исходной — совпадение пикселей ниже порога, восстановление невозможно.

## Экспорт

PNG, JPEG, HEIC; копирование в буфер, «Поделиться», перетаскивание; сжатие под заданный размер — подбор качества и масштаба в ядре.
