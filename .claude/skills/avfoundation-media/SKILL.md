# Видео на AVFoundation

## Запись

- macOS 15+: можно использовать `SCRecordingOutput` для записи напрямую в файл; macOS 14: `SCStream` → `AVAssetWriter`.
- `AVAssetWriter` с видеовходом HEVC или H.264 (настройка REC-04) и отдельными аудиовходами для системного звука и микрофона.
- Время — по `presentationTimeStamp` кадров; сессия стартует с первого кадра.
- Перед записью и каждые 10 секунд — проверка свободного места (REC-06); при критическом остатке — корректная остановка.

## Модель проекта монтажа (неразрушающая)

```json
{
  "version": 1,
  "clips": [{ "itemId": "uuid", "sourceStart": 0.0, "sourceEnd": 12.5, "speed": 1.0, "muted": false, "volume": 1.0 }],
  "cuts": [],
  "crop": { "aspect": "16:9", "rect": [0, 0, 1, 1] },
  "overlays": [{ "objectId": "uuid", "start": 2.0, "end": 5.0 }],
  "blurRegions": [{ "rect": [0.1, 0.2, 0.3, 0.1], "start": 4.0, "end": 9.0, "style": "pixelate" }],
  "music": null
}
```

Объекты оверлеев — те же, что в редакторе изображений (скилл `annotation-editor`).

## Сборка из проекта

- `AVMutableComposition`: вставка диапазонов клипов, `scaleTimeRange` для скорости.
- `AVMutableAudioMix` для громкости по дорожкам.
- Аннотации: `AVVideoCompositionCoreAnimationTool` со слоями, видимость по времени через анимации `opacity`.
- Размытие областей по времени: собственный компоновщик (`AVVideoCompositing`) на Core Image. Тот же компоновщик используется для предпросмотра, чтобы результат совпадал.
- Кадрирование и пропорции — через `renderSize` и трансформацию.

## Экспорт

- MP4: `AVAssetExportSession` с подходящим пресетом или `AVAssetReader` + `AVAssetWriter`, когда нужен контроль битрейта (подбор под размер файла, VID-05).
- GIF: `AVAssetImageGenerator` или `AVAssetReader` выдаёт кадры с нужной частотой и шириной → пути к кадрам или буферы передаются в ядро (`imaging::gif`) → ядро квантует палитру и пишет файл.
- Прогресс и отмена во всех экспортах.

## Таймлайн

- Превью кадров — `AVAssetImageGenerator` с допуском по времени, кэш на диске.
- Звуковая волна — уровни, посчитанные один раз при импорте и сохранённые рядом с медиа.

## Проверка

Запись 30 минут 60 к/с без потерь кадров; экспорт 5-минутного ролика с обрезкой и аннотациями; воспроизведение результата в QuickTime и в браузере.
