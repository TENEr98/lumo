# Архиватор

## Форматы и крейты (лицензии сверить перед добавлением)

| Формат | Чтение | Создание | Крейт-кандидат |
| --- | --- | --- | --- |
| ZIP (+ AES-256, ZipCrypto на чтение) | да | да | `zip` с функцией AES |
| 7z (+ AES-256) | да | да | `sevenz-rust2` или `sevenz-rust` с функцией AES |
| TAR | да | да | `tar` |
| gzip / bzip2 / xz / zstd | да | да | `flate2`, `bzip2`, `xz2` или `liblzma`, `zstd` |
| RAR4/RAR5 | да | **нет** | `unrar` (обёртка над UnRAR) |
| ISO (v2) | да | нет | выбрать при начале v2 |

Если крейт-кандидат не тянет нужную функцию — зови `architect`, не пиши свой формат.

## RAR — только распаковка

Лицензия UnRAR разрешает использовать исходники только для распаковки и запрещает воссоздавать алгоритм сжатия RAR. Создание RAR не реализуется ни в каком виде. Текст лицензии UnRAR включается в экран «Лицензии» приложения.

## Имена файлов

- Если в ZIP установлен флаг UTF-8 (бит 11) — имя в UTF-8.
- Иначе — эвристика: декодировать как CP437, CP866 и CP1251 через `encoding_rs`, выбрать вариант, где больше допустимых кириллических/латинских букв и нет управляющих символов. Пользователь может переключить кодировку вручную в просмотре архива.
- Тест: архив, созданный стандартными средствами Windows с русскими именами, распаковывается с правильными именами (ARC-04).

## Безопасность (ARC-05) — обязательно в каждой распаковке

- Нормализовать путь записи; отклонить абсолютные пути, `..`, символические ссылки, указывающие за пределы папки назначения.
- Предел коэффициента сжатия на запись (например, 1000:1) и предел итогового размера (настройка, по умолчанию 20 ГБ или свободное место минус запас) — превышение останавливает распаковку с понятной ошибкой.
- Предел глубины вложенности, если включена распаковка вложенных архивов.

## Поведение

- Просмотр без распаковки: список записей с размерами и датами, ленивая загрузка для больших архивов.
- Распаковка выбранных записей, прогресс, отмена; при отмене удаляются частично записанные файлы.
- При упаковке по умолчанию исключать `.DS_Store` и `__MACOSX` (ARC-08).
- Пароль никогда не логируется и не сохраняется без явного согласия пользователя.
