# Чек-лист ревью

## 1. Соответствие

- [ ] Изменение закрывает заявленный код требования и не делает ничего сверх него без записи в progress.
- [ ] Нет противоречий БФТ и принятым ADR.
- [ ] Логика лежит в правильном слое (скилл `lumo-architecture`).

## 2. Корректность

- [ ] Обработаны: нет разрешения, нет iCloud, нет сети, нет места, отмена, повреждённые данные, очень большой файл.
- [ ] Нет паник и `unwrap` на пути из Swift в Rust; нет force-unwrap в Swift без объяснения.
- [ ] Долгие операции не блокируют главный поток.

## 3. Безопасность и приватность

- [ ] Распаковка защищена от выхода путей и архивных бомб.
- [ ] Размытие при экспорте необратимо.
- [ ] Скрытые элементы буфера не сохраняются и не синхронизируются.
- [ ] Пароли и содержимое буфера не попадают в логи.
- [ ] Никаких сетевых обращений, кроме CloudKit; никаких сторонних SDK.

## 4. Лицензии

- [ ] Новые зависимости записаны в `docs/kb/10-dependencies.md` с лицензией.
- [ ] Нет GPL/AGPL, нет FFmpeg; UnRAR используется только для распаковки.

## 5. Производительность

- [ ] Изменения на горячих путях (захват, открытие панели буфера, поиск) не ухудшают NFR-05 — NFR-08; если затронуты — есть замер.

## 6. Тесты и документация

- [ ] Тесты проверяют именно критерий приёмки, а не только «не падает».
- [ ] Для ручной части есть сценарий в `docs/test-scripts/`.
- [ ] Строки интерфейса локализованы на три языка.
- [ ] Обновлены `docs/progress.md` и нужные разделы `docs/kb/`.

## Вердикт

«Можно принимать» / «принимать после исправлений» / «вернуть» + замечания по важности с файлом и строкой.
