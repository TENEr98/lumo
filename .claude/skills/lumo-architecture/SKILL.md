# Архитектура Lumo

## Слои

| Слой | Где | Отвечает за |
| --- | --- | --- |
| `lumo-core` | `core/crates/*` | Хранилище, поиск, архивы, история буфера, растровые операции, GIF, миниатюры, сериализация записей синхронизации |
| `lumo-ffi` | `core/crates/ffi` | Единственная точка экспорта через UniFFI; тонкий слой над крейтами ядра |
| `LumoKit` | `apple/Packages/LumoKit` | Swift-пакет: обёртки над ядром, сервисы, модели представлений, общий для всех целей |
| Приложения | `apple/Lumo-macOS`, `apple/Lumo-iOS` | Точки входа, окна, сцены, специфичный для платформы интерфейс |
| Расширения | `apple/Extensions/*` | «Поделиться», запись экрана (ReplayKit), клавиатура |

## Крейты ядра

- `storage` — SQLite (rusqlite, режим WAL), миграции, FTS5, CRUD элементов библиотеки.
- `archive` — чтение и создание архивов (см. скилл `archive-engine`).
- `imaging` — размытие, пикселизация, обрезка, склейка, сжатие под размер, миниатюры, кодирование GIF.
- `clipboard` — модель элемента буфера, правила дедупликации и хранения; само чтение буфера — в Swift.
- `sync-model` — преобразование элементов в записи для CloudKit и обратно, версии, правила слияния; сетевые вызовы — в Swift.
- `ffi` — UniFFI-экспорт.

## Правило выбора слоя

Спроси: «Нужно ли это одинаково на Mac и iPhone и не требует ли системного фреймворка?» Да — Rust. Нет — Swift. Сомнение — зови `architect`.

## Сервисы Swift (в LumoKit)

`CaptureService`, `RecordingService`, `MediaEditingService`, `PasteboardMonitor`, `SyncService`, `LibraryStore` (обёртка над ядром), `PermissionCenter`, `OCRService` (Vision). Каждый сервис — за протоколом, у каждого есть заглушка для превью и тестов.

## Потоки данных

1. Захват/запись/копирование в Swift → файл в контейнере приложения → `LibraryStore.add(...)` в ядро → ядро пишет метаданные и строит миниатюру.
2. Ядро помечает элемент «нужно синхронизировать» → `SyncService` берёт изменения через FFI → CloudKit.
3. Изменения из CloudKit → `SyncService` → ядро применяет по правилам слияния из `sync-model`.

## Файлы на диске

- macOS и iOS: контейнер общей группы приложений (`group.<bundle-prefix>.lumo`), чтобы расширения писали в ту же библиотеку.
- `library.sqlite`, папки `media/<id>/original.*`, `media/<id>/thumb.jpg`, `projects/<id>.json`.

## Нельзя

- Импортировать Apple-фреймворки в ядро или вызывать сеть из ядра.
- Дублировать в Swift логику, которая уже есть в ядре.
- Делать синхронные вызовы ядра на главном потоке, если операция может длиться дольше 16 мс.
