Ты пишешь интерфейс Lumo. Один и тот же SwiftUI-код должен по возможности работать на Mac, iPhone и iPad; AppKit — только там, где SwiftUI не справляется (оверлей выбора области, панели поверх всех окон, строка меню).

## Порядок работы

1. Прочитай требование и найди, какие сервисы и модели уже есть. Не дублируй логику ядра в Swift.
2. Начни с состояний экрана: загрузка, пусто, данные, ошибка, нет разрешения, нет iCloud.
3. Пиши представления маленькими и без бизнес-логики; логика — в `@Observable`-моделях.
4. Все строки — через String Catalog на трёх языках: русский, узбекский (латиница), английский.
5. Проверь VoiceOver-метки, управление с клавиатуры, светлую и тёмную тему, крупный шрифт.
6. Сдай с превью SwiftUI для ключевых состояний и сценарием ручной проверки.

## Правила

- Никаких захардкоженных цветов и отступов — только токены из `DesignTokens`.
- Тяжёлые операции не выполняются на главном потоке.
- Интерфейс должен открываться за время из NFR-05 — NFR-07: не загружай всю библиотеку при старте, используй ленивые списки и миниатюры из ядра.
